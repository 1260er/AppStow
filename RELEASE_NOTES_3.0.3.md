# AppStow 3.0.3 – Release notes / Versionshinweise

## Deutsch

**Verbesserungen in 3.0.3**

- Schnellere Rückkehr zur konfigurierten Startansicht.
- Sichtbarkeit in „Zuletzt verwendet“ unabhängig vom Startverhalten.
- Normale Android-Vorschau bleibt erhalten.
- Schnellere und abgesicherte Icon-Ladevorgänge.
- Weniger unnötige Speichervorgänge bei der Sortierung.
- Weniger überflüssige UI-Aktualisierungen.
- Erweiterte Regressionstests und erfolgreiches Final-Audit.
- Dev-241 erfolgreich auf einem Smartphone getestet.

**Version:** 3.0.3, Versionscode 16, Paket `de.pritcloud.appstow`.

Das manuelle Sicherungsformat v3 bleibt mit AppStow 3.x kompatibel. Sicherungsdateien aus 2.x können weiterhin nicht importiert werden.

Der GitHub-Dev-Build verwendet eine eigene Paketkennung. Ein gesondertes direktes Geräte-Upgrade von GitHub-Stable 3.0.2 auf 3.0.3 wurde nicht gemeldet.

## English

**Improvements in 3.0.3**

- Faster return to the configured start view.
- Independent Android Recents visibility control.
- Normal Android Recents previews remain enabled.
- Faster, safer asynchronous app icon loading.
- Fewer redundant sorting-persistence writes.
- Reduced intermediate overview refreshes.
- Additional regression tests and successful final audit.
- Dev-241 tested successfully on a physical Android device.

**Version:** 3.0.3, versionCode 16, package `de.pritcloud.appstow`.

Manual backup format v3 remains compatible with AppStow 3.x. AppStow 2.x backup files remain incompatible.

Development builds use a separate package ID. A separate physical-device in-place upgrade from GitHub-stable 3.0.2 to 3.0.3 has not been reported.

## F-Droid

F-Droid uses its independent update and reproducible-build pipeline. GitHub publication does not imply immediate availability on F-Droid.
